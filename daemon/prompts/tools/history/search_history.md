Search your own conversation history, including compacted older messages and the active conversation window. Use this when the user asks what you discussed before, when you need to verify a past exchange, when you need messages from a specific time range, or when the answer may be in the transcript rather than in curated memory files. Provide `query` for keyword search, `start_time` and/or `end_time` for an inclusive RFC3339 time range, `model` to restrict to assistant messages minted by a matching model, or combine them. Returns a small set of matching messages with role, timestamp, minting model (when recorded), and clean text snippets.

Only visible chat text is searched — private thinking and tool-call/tool-result payloads are never matched or returned. Multi-word searches keep the matches with the best term coverage instead of flooding the result with messages that mention only one common word. Results are deduplicated and ranked by relevance blended with recency; time-range-only queries are returned oldest-first. Unselected regenerated answers are omitted unless `include_alternatives` is true. `searched_messages` reports the full corpus size, not the number returned. Text is clipped to `excerpt_chars` (default 240, max 2000); raise it when you need a fuller quote.

Each result's `model` field is the model that generated that message (regenerated alternatives carry their own). It is `null` on user turns and on messages stored before model tracking, and the `model` filter skips those — so an empty result for an old period means "not attributable", not "never said". To audit how you sounded on one model versus another, combine `model` with a time range and compare excerpts from each. The `model_history` tool tells you which models served you over a period.
