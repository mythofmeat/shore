Find workspace files matching a query. Uses hybrid ranking (semantic + lexical) by default so paraphrased queries can find the right file; pass `mode: "lexical"` for substring-only or `mode: "vector"` for pure semantic similarity. Best for fuzzy concept questions ("anything about my dog?"). For exact text, paths, or directory structure, use `bash` with rg, find, or ls.

Results contain paths, line numbers, and excerpts. Follow up with `bash` to read relevant files using cat or sed; an excerpt may omit context that changes its meaning. Follow file references and try different wording before concluding there is no relevant record. Use `search_chat_logs` for archived conversations.

Set `context` to the desired characters on each side of a hit (default 500, range 0–10000), and `max_results` to the desired number of hits (default 20, maximum 100). Windows stay centered on the match, with ellipses wherever context is omitted. Context automatically shrinks across all returned hits to target a 12000-character response, including paths and notices; results and full matches are never removed to meet this budget, so those alone can exceed it. Semantic hits without a literal match use a best-effort term or opening snippet. The more-matches notice indicates additional hits beyond `max_results`.
