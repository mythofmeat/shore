Read a file on the daemon host. Relative paths resolve from the workspace; absolute paths are accepted. Access is limited by the daemon user's OS permissions, as with Bash.

UTF-8 text is returned with one-based line numbers. A page contains at most 2000 lines, with at most 2000 characters per line, and is bounded by the configured result limit. Partial views identify omitted content and the next line offset. Empty files and offsets beyond EOF are reported explicitly.

Markdown files also expand unique local image references fully visible in the returned page, while preserving the numbered source. Image paths resolve relative to the Markdown file. Inline and reference-style Markdown images are supported; code examples and remote URLs are ignored. Expansion requires a Markdown file no larger than 1 MiB. Missing, unsupported, or oversized images are reported without failing the text read.

PNG, JPEG, WebP, and GIF files up to 5 MiB are returned as actual image input. Large images are resized for transport; GIFs use the first frame. Each result sends at most 20 images, within the configured byte budget for resized image data (5 MiB by default); images considered in order that do not fit are listed as not sent without failing the read, and later smaller images can still be sent. Image delivery requires a supported model and endpoint; failures are reported explicitly. Offset and limit apply only to text. Directories, special files, unsupported binary formats, and invalid UTF-8 are rejected.
