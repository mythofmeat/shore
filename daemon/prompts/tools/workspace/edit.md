Replace exact text in an existing UTF-8 file. With replace_all=false (default), old_string must occur exactly once. Missing or ambiguous matches, identical replacements, binary files, and invalid arguments fail without writing. Whitespace and line endings are significant. An empty new_string deletes the matched text; an empty old_string is rejected. replace_all=true replaces all non-overlapping matches. Paths and symlinks follow the same host access rules as bash. Filesystem write failures can leave partial changes.
