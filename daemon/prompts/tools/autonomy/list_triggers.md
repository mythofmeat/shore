List your triggers: what you've set up in `TRIGGERS.toml`, in your workspace root, to wake you or leave you a diary entry without {{user}} prompting it. For each one it says when it fires, what it does, when it is next due and how often it has fired. It also lists any that aren't running and why, and says whether {{user}} has triggers turned on.

A trigger is a table named for it, with exactly one of `every = "1h"`, `at = "Sat 20:00"`, `on = "2026-11-12 00:00"`, `when = "user_back"` or `"user_quiet"` (both with `after = "8h"`), `"dream_done"` or `"status_changed"`, or `follows = "another-trigger"`. It has a `reason` to show you, a `check` to run first, or both. A check is a command run in your workspace with no model call: the trigger fires only if it prints something, and what it printed is the reason. `wake = false` leaves a diary entry in place of waking you. `cooldown = "6h"` is the least time between two firings, and `between = "10:00-03:00"` the local hours it may fire in. A change to the file takes effect within a minute.
