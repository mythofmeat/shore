Save a picture you were shown into the workspace. {{user}}'s pictures and pictures in tool results come with an id, as in `[picture 3f2a91c0]`; pass that id, or at least its first 6 characters, as `picture`. Pictures you were shown stay in an image cache only until it fills up, so save the ones worth keeping: a picture that has been evicted from the cache can no longer be saved, and the result says so. `path` is relative to the workspace root and must stay inside the workspace; missing folders are created and an existing file is never replaced. A path without an extension gets the picture's own, such as `.png` or `.jpg`.
