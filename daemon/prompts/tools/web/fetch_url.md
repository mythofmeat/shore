Fetch and read the content of a web page, returning its text. Use when a `web_search` result looks relevant and you need the full context, when {{user}} pastes or mentions a URL you should actually read, or when you want to follow a specific page you already have in mind. Best paired with `web_search` to find candidate URLs first. Returns plain text; complex interactive pages, paywalled content, or heavily JS-rendered sites may return limited or no content.

Returns readable text preserving headings, paragraphs, lists, code blocks and link destinations. Long pages are paginated by Unicode character: use the returned offset with the same URL and limit to continue. The default limit is 12000 characters (maximum 50000). Each call fetches the page again, so offsets assume its content is unchanged. A separate notice identifies a response cut off at the download limit; that missing content cannot be retrieved by increasing offset.
