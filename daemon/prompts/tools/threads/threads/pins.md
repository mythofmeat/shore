What to keep in the thread's prompt. A workspace file is given as a path relative to the workspace root, or as a link like `[[notes]]` or `[[lighthouse/]]`. A pin starting with `!` is a shell command instead, such as `!git log --oneline -5`: it runs in your workspace when the thread's prompt is refreshed, and its output is kept there. In an `edit` this is the thread's whole new list, and an empty list clears it.
