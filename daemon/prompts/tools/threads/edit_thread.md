Change a side thread's label, purpose or files when they've gone stale: its notes moved to a new folder, another file should come along, or the purpose no longer says what the thread is for. It works on any side thread, whoever started it, but not on the home thread, or on a thread {{user}} has locked so that only {{user}} changes it.{{#if list_threads}} `list_threads` shows which threads are locked.{{/if}}

Give only what should change. An empty `label` or `purpose` clears it. `files` replaces the thread's whole list, so name every file it should keep, or give `[]` to clear it. They're paths or `[[links]]` the way `read` takes them, where a folder link like `[[lighthouse/]]` means its INDEX.md, and they must be text, at most 32 KB each and 128 KB together; if any of them can't be found or doesn't fit, nothing changes, the label and purpose included. You'll see the change from that thread's next turn, the same as when {{user}} changes it.
