Read this first

I ran every surface that only reads state. Nine of them — log, memory, alt, character --info, and the trace dumps — carry your actual conversations with qifei, so for those I captured the JSON shape only: key names and value types, no values. Nothing personal is in this document. Mutating surfaces (send, regen, config reload, usage recalculate, provider refresh, the five debug triggers) were not run against your live daemon.

Findings split four ways. Wrong means the output states something false. Leak means it exposes a secret. Shape means the command or flag structure is the problem, not the rendering. Vocabulary means it looks different from its neighbours for no reason — these are the ones that vanish for free once there's one rendering vocabulary.

Fix before anything else

01
Your MCP bearer token prints in plaintextLeak

shore config renders every configured MCP server including its headers, unredacted, with no --show-secrets gate. The WHOOP server's Authorization header came out in full:

mcp: whoop: url http://mcp-whoop:3000/mcp headers: Authorization Bearer c78911b4d4…<64 hex chars>

It landed in my capture files and my context. I scrubbed the files. Rotate the token. On the rebuild: secrets redact by default everywhere, and anything that reveals them is an explicit flag.

08
Six bracket notations, no legendVocabulary
$ shore model setting temperature 1 [static_default] top_p (unset) [(default)] reasoning_effort max [character_model] {high, max} sdk deepseek [static_default] $ shore model * deepseek-v4-pro deepseek [discovered] $ shore model --background heartbeat (unresolved) [inherited: active chat model]

[static_default] and [(default)] are different states rendered in near-identical text. [discovered] is provenance, [character_model] is precedence, {high, max} is an allowed-value set, [inherited: …] is a sentence. All wearing the same brackets. And (unresolved) [inherited: active chat model] says one thing twice.

09
The label column silently breaks on long labelsVocabulary
$ shore model --info Qualified deepseek:deepseek-v4-pro Model ID deepseek-v4-pro SDK deepseek Provider deepseek Base URL https://api.deepseek.com Max output tokens 8192 ← label is 17 chars; column is 13

Any label ≥13 characters eats its own column and gets one space instead of alignment. There's a special case in the row helper that inserts that single space, so this was noticed once and papered over rather than fixed.

10
Two phrasings for hidden itemsVocabulary
$ shore model (440 hidden — use `shore model --all` to include them) $ shore provider models anthropic hidden (8 — pass --all to include)

Same concept, same flag, opposite word order, one with backticks and a full command, one without. Both invented at the site that needed them.

11
Padded rows ship trailing whitespaceVocabulary

tools pads names to a fixed width even when nothing follows, so half its lines end in spaces (" · generate_image "). Same in the Sub-agents label row, which prints a label with an empty value purely to create a heading. Cosmetic on screen, visible the moment you pipe or diff it.

18
Multi-line values break the indent structureVocabulary

Everything else in config is a strict indented tree. Prompt bodies are emitted flush-left at column 0, so the tree structure collapses exactly where the content is longest, and there's no way to tell where the value ends and the next key begins except by recognising it.

19
Six behaviours on one verbShape

config alone prints the tree; config KEY reads; config KEY VALUE writes; --path prints a path; --check validates; --reset clears; --toml and --json and -a change the renderer; config reload is a subcommand that prompts on stdin. Read and write are the same word with no confirmation between them.
